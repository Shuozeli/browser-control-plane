Browser Fleet Control Plane

A two-layer Rust gRPC system for routing browser automation across many machines, Chrome profiles, and logged-in platform accounts.

Tailscale-first operator surface
Summary Architecture Routing Flow Lease Model Machine Controller HTML Console Documents

What We Are Building

Global Controller

Owns registry, account-to-profile mapping, routing decisions, machine heartbeat, and leases. It does not execute browser actions.

Machine Controller

Runs once per computer. It manages local Chrome instances, profile paths, CDP ports, health checks, and browser proxying.

Client

Asks the global controller for a route and lease, then sends browser work to the selected machine controller.

Architecture

Routing Flow

Lease State Model

Every browser operation carries lease_id, profile_id, and fencing_token. The machine controller validates these before touching Chrome.

Rule Reason
One profile, one active lease Prevents two jobs from operating the same account.
Fencing token required Rejects stale delayed requests after lease renewal.
Machine validates locally Do not trust client-side routing data alone.

Machine Controller Responsibilities

Area Responsibility Storage
Profiles Map profile IDs to local Chrome profile paths. SQLite
Runtime Launch, stop, and health-check Chrome instances. SQLite + process table
Ports Allocate CDP ports from a configured local range. SQLite
Proxy Execute snapshot, action, evaluate, and scripts. pwright bridge

HTML Console Proposal

Serve Model

The global controller serves a Tailscale-only operator UI at $TAILSCALE_IP:7080 and advertises the full MagicDNS URL.

Scope

The UI is for understanding fleet state and debugging routes. It is not the browser automation API and it does not expose raw CDP endpoints.

View Shows First Phase
Fleet Machines, status, heartbeats, labels. Read-only
Profiles Profile path, owning machine, account mapping. Read-only
Routes Dry-run route selection and rejection reasons. Phase 2
Leases Lease owner, purpose, expiry, fencing token fingerprint. Phase 3
